DokanOS Sync Architecture

Scaling order sync from 1 operator to 100 users across 500 WooCommerce stores — without double-sends, stalls, or 7-hour outages.

Current system today

Timer-driven polling. A single worker drains a shared queue 20 rows at a time, sequentially.

GitHub Actionscron every 5/15 min
→
sync-worker1 process · 20/batch
→
WooCommerceREST per row
Single point of failureOne worker, one process. If it dies, nothing syncs.
Sequential20 rows then loop. 500 stores = minutes of head-of-line blocking.
Timer driftpg_cron died 2026-07-29; GitHub schedule died on repo rename.
Shared queueNo per-store isolation — one slow store stalls all others.

Target system revamp

Event-driven. WooCommerce pushes changes; a durable queue fans out to a parallel worker pool with idempotency and per-store circuit breakers.

IdempotentEvery event keyed; replays never double-send.
Per-store breakerOne failing store is isolated, not systemic.
DLQPoison events go to dead-letter, never block the queue.

Phased roadmap

1

Stabilize (now)

Repoint git remote to the renamed repo, re-enable the schedules in GitHub UI, confirm cron token in vault. Keep the existing worker but make it idempotent with a dedup key.

No new infra · unblocks today
2

Webhooks in (next)

Register WooCommerce webhooks → webhook-in edge fn. Verify signature, normalize, enqueue to a sync_events table. Keep the timer as a fallback backfill for missed webhooks.

Edge fn + 1 table · cuts idle polling
3

Queue + pool

Adopt PGMQ (or the sync_events table with SKIP LOCKED). Run a worker pool that claims per-store batches in parallel. Add circuit breaker + dead-letter status. Retire sequential 20-row loop.

PGMQ / SKIP LOCKED · parallelism
4

Resilience

Per-store backoff, exponential retry, DLQ dashboard, replay tooling. Monitor queue depth + send latency per store.

Observability · self-healing
5

Scale

Horizontal worker replicas behind a queue, sharding by store id. 500 stores × 100 users handled by N parallel workers with bounded concurrency.

Horizontal scale · 500 stores
